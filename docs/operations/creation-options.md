# Creation defaults and shortcuts

Super administrators can set **System Settings → Creation Defaults → Default Generation Model**. The choice identifies an active channel and duration; it is preselected only when opening a new creation page. Users can still select another model. Disabled, deleted or retired channels fall back to manual selection. This uses the existing settings table and requires no migration.

Batch ZIP download filenames use `APP-region-批次-batchID.zip`, for example `TopShort-巴西-批次-1899.zip`. Illegal filename characters are replaced and overly long labels are shortened; Chinese names are preserved. The archive still contains only completed, available videos and retains existing per-video names and access checks.

The reference-material drawer searches names locally, including Chinese and case-insensitive English. Filtering does not change selected materials; clearing the search restores all cards. Closing without applying cancels selection changes.

APP name and batch name inputs offer the latest three distinct nonempty values. Values are remembered when leaving the field or submitting and can be selected by pointer or arrow keys/Enter. Records live only in this browser's local storage, separated by logged-in user ID; they do not sync across devices. Clearing browser site data clears this history. No prompts, passwords, or proxy credentials are stored by this feature.
