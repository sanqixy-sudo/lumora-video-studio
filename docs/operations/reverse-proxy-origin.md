# HTTPS 反向代理与设置保存

`PUBLIC_ORIGIN` 可设为浏览器实际使用的完整来源，例如 `https://video.example.com`。仅在代理保留 Host、但应用看到 HTTP 而浏览器使用 HTTPS 时需要；默认留空。

同源校验仍允许直接访问的内网来源。额外的公共来源必须精确匹配配置的协议、域名和端口，且请求 Host 必须与配置相同。不会从客户端提供的 X-Forwarded-* 头推导可信来源，跨站请求、其他来源和角色越权继续拒绝。

NAS 本次配置为 `PUBLIC_ORIGIN=https://video.7cloudvps.com`。修改部署环境变量后需重建容器（不需要数据库迁移），不可通过普通运行设置表单修改。请求代理、下载代理及任务并发配置不受影响。

异步表单明确请求 JSON 错误，来源校验失败显示具体原因，成功仍沿用 303 页面跳转。

已保存的代理地址显示在“当前地址”提示中，输入框留空表示保留。保存默认模型等其他设置时不会重复提交内网代理 URL，避免公共网关将无关设置保存误判为内网 URL 请求。填写新地址仍按原有验证流程更新。
