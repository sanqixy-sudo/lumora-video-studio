# 多批次嵌套 ZIP 下载

普通用户的批次列表支持勾选、全选当前页（最多 20 个）、取消选择及选中数量/视频数量提示。没有本地可下载视频的批次不可勾选。选择仅作用于当前页，翻页后重新选择。

下载“批次合集-日期-时间-N个批次.zip”，总包内每个批次独立一个“包名-地区-批次-id.zip”。沿用单批次视频命名，仅打包已完成且本地存在的最新执行结果，不包含生成失败、待完成或历史失败尝试。单个所选批次已无文件时拒绝打包，避免误以为完整下载。

采用浏览器原生附件下载。打包完成后用无权限含义的短期随机 Cookie 通知页面，显示“浏览器已开始下载”，不将 ZIP 全量读取为浏览器 Blob。服务端直接把内层 ZIP 写入外层 ZIP 的文件项，视频不重复压缩，不产生完整内层临时副本。

每次最多 20 个批次，每个 Web 进程同一时间仅执行一次批次合集打包。先校验全部批次所有权，再读取文件；检查剩余磁盘空间。构建失败或响应结束（包括断开）均清理临时文件。空间不足、其他打包占用、文件变化等错误会在列表页展示。无需数据库迁移，也不调用视频生成 API。
