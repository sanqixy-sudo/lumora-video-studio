# 多批次逐个下载 ZIP

普通用户批次列表支持勾选、全选当前页（最多 20 个）、取消选择及选中数量/视频数量提示。没有本地可下载视频的批次不可勾选。选择仅作用于当前页。

点击“逐个下载选中批次”后，依照列表顺序逐个准备并发起独立附件下载，不生成总压缩包。每个文件为“包名-地区-批次-id.zip”，内部直接放视频。只包含当前用户已完成、本地存在的最新执行结果。

使用单批次接口 `/app/job-batches/{id}/download-zip`。可选随机 `download_token` 对应短期 Cookie，只标记附件已准备好。收到准备完成反馈才发起下一批次，不将 ZIP 全量加载为浏览器 Blob。页面显示“已发起下载”，文件传输完成情况以浏览器下载列表为准；浏览器可能要求允许多个文件下载。

准备中禁用重复提交。已发起下载的批次取消勾选；单个批次出错后继续后续批次，错误及未发起批次保留供重试。登录失效或准备超时则停止队列。刷新页面不会自动继续队列。

服务端校验批次所有权、剩余磁盘空间，每个 Web 进程同一时间仅执行一次批次 ZIP 构建，使用磁盘文件及 ZIP_STORED，构建失败或响应结束（包括断开）清理临时文件。原单批次下载链接仍可使用。无需数据库迁移，不调用视频生成 API。
