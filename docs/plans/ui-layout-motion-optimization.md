# 工作台排版与流畅性优化记录

日期：2026-10-21。状态：已实现第一轮排版与过渡优化，待浏览器实测。

## 目标与边界

保留现有高效的创作、任务和计费操作流程，优化信息的视觉主次、首屏空间利用和界面切换的稳定感。Nexiv 的授权站预览和仓库截图只作为排版参考，不复制其导航、功能流程或配色。

## 优化方向

1. **减轻外层装饰。** 保留当前品牌色，将明显的玻璃、模糊和阴影集中在主要工作面或浮层。侧栏、顶栏和提交栏降低视觉重量，避免多层悬浮卡片同时争夺注意力。
2. **提高创作首屏的有效面积。** 保留模型、APP、地区、规格、素材、提示词的现有顺序与功能；收紧标题、步骤提示和区块间距。评估将素材栏从现有的 280px 缩窄，使提示词编辑区更宽，并让首屏更早看到编辑内容。
3. **压缩使用日志顶部的纵向堆叠。** 保留时间、用户、任务筛选以及成本汇总；将常用筛选与汇总排得更紧凑，使桌面首屏尽量看到任务记录。保留现有的详情弹窗及左右信息、视频布局。
4. **稳定界面状态变化。** 保留现有短促的切页和抽屉过渡。使用日志详情加载时预留接近最终内容的空间，减少从单行加载文字切换到两栏内容时的跳变；弹窗开合使用克制的反馈。不要给高频控件和整页叠加更长的动画。
5. **实测性能后决定模糊强度。** 大面积 `backdrop-filter` 是需要验证的性能候选，不把代码推断当作掉帧结论。若低性能设备有卡顿，再减少模糊面积或改为不透明表面。

## 验收观察

- 桌面、中等宽度和手机宽度下，创作页的主要编辑区与使用日志记录都能较早进入视野，且没有内容遮挡。
- 快速切页、开关侧栏、打开并关闭日志详情时，状态反馈及时，内容不明显跳动；弹窗加载中与加载后的尺寸变化受控。
- 键盘操作、焦点返回和减少动态效果设置保持可用。

## 本轮实施

- 创作页收紧共享设置、素材栏和提交栏，把编辑区宽度更多留给提示词；顶栏、侧栏和工作面减少模糊与阴影叠层。
- 使用日志把精确筛选收进可展开区域，汇总与任务列表更靠近页面顶部；详情弹窗加载时保留双栏占位，并加入短促开场过渡。
- 创作草稿保存在当前浏览器、按账号隔离，30 天内可手动恢复；提交成功后清除。
- 任务详情可用现有配置和提示词再次创作。原模型不可用时要求重新选择并核对素材。
- 使用日志区分生成中、成功待核对、失败待排除和已结算；管理员可将成功待核对任务加入重新核对队列。

浏览器视觉与交互验收仍需在运行环境中完成。
