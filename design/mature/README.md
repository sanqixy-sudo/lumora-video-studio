# Lumora 柔光磨砂工作台 · 五页样板

本轮交付为设计确认阶段。登录、生成、任务详情、后台用户和每日用量采用实际 Jinja 模板、现有原生 JavaScript 业务交互及本地模拟数据。尚未推广到全部 31 页，也未部署服务器。

- 样板评审：<http://127.0.0.1:8101/design>
- 生成页：<http://127.0.0.1:8101/app>
- 当前旧版预览仍为 8100；8101 的“新旧并列”使用本轮冻结的 v9.3 本地基线。
- 登录、生成、保存只返回模拟结果，不连接数据库或上游。
- 登录页已按后续确认改为公开作品封面墙和交替反向鼠标跟随，详见 [登录页更新](./LOGIN_WALL.md)。

## 本地运行

在项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_design_preview.ps1`，以隐藏后台进程启动预览。重复执行只检查已运行服务，不创建重复实例。开发时也可执行 `.venv/Scripts/python.exe -B scripts/preview_mature.py --serve` 在当前终端运行。
预览监听 127.0.0.1:8101。`templates/` 和 `static/` 是可继续编辑的样板源码；修改模板后重启此服务，样式可直接刷新。

`scripts/preview_mature.py` 使用模板优先加载和模拟场景，未新增生产 API 或生产页面地址。其他页面仍使用现有模板，不能把从样板导航进入的所有页面都算作新版。

当前版本 `glass-2` 将已确认的登录磨砂材质延展至业务样板，详见 [本轮设计与验收](./GLASS_2_REVIEW.md)。

## 已实现

1. 微紫灰双主题和 208 / 64px 导航，居中磨砂登录面板、公开作品拼贴、手机静态背景。
2. 生成页标题与额度、参数工具栏、280px 素材栏、完整缩略图、独立提示词列表、底部提交栏。
3. 提示词默认 96px、聚焦后 168px；失焦保留高度，手动收起；新增和导入入口固定，100 条导入不逐项入场。
4. 任务详情主视频和右侧状态区、下方分组参数，远端 ID 单独一行，日志切换不重新创建视频。
5. 用户统计、筛选和表格形成连续区域；月报占用内容宽度，保留日期固定列、热度、月份切换和权限差异。
6. 保留现有抽屉、菜单、导航、最近任务轻动效，登录背景按横向鼠标位置交替滑动。
