# 登录页：公开作品封面墙

2026-09-08，根据用户新确认方向替换初稿的三张插画和左右分栏。

## 原站实际观察

实际用 Chromium 打开 `https://guangdada.net/modules/auth/login`，在 1920×1080 视口将鼠标移到中心、左、右、上、下并截图。

- 背景整体倾斜 -15°，四排图片，每排七张。
- 左侧鼠标位置 x=80：四行约 -137 / +137 / -137 / +137px。
- 右侧 x=1840：方向反转。
- x 保持居中、上下移动时，水平位移接近 0；原站主要由横向鼠标位置驱动。
- 登录面板不跟着图片移动，背景色透过模糊面板呈现。
- 证据：`evidence/reference-pointer/measurements.json`，以及 center / left / right / top / bottom 截图。

第一次加载等待 DOM 就绪超时；第二次实际浏览器加载成功后才据实修正，不将之前的整墙轻移冒充原站行为。

## 当前实现

- 四行交替反向跟随，横向极值 ±150px，忽略鼠标 Y；图片层统一倾斜 -15°。
- 四行分别使用 700 / 620 / 560 / 500ms 可中断 transform 过渡。参考的是实际观测方向和幅度，没有声称精确复刻原站内部弹簧参数。
- 鼠标事件每帧合并一次，只写四个行容器的 transform；停止移动后没有持续的 requestAnimationFrame 循环。
- 手机、触屏和减少动态效果保持静态；离开窗口、隐藏页面、窗口尺寸或设备偏好改变时复位。
- 居中 560px 面板，缩短表单，增强静态磨砂透色；输入框保留实色底，背景不参与点击与键盘导航。
- 每次进入重新排列，不在填写时随机换图。缺图不阻塞登录。

## 素材来源与范围

用户先提出后台现有素材，后明确选择“公开作品的视频封面，更接近参考图”。只读查询已完成、开启广场展示且未自用保护的作品，直接读取现有封面；没有改数据库、下载视频或调用生成接口。

从候选的近期 300 个输出中选择 24 张不同封面，压缩 WebP 合计 678,722 字节（约 663 KiB）；28 个画面位置复用这 24 张图，不增加图片下载数量。出处范围记录在 `evidence/login-poster-source.json`。

当前是本地样板快照，不自动随线上保护状态变化。全站落地时需要在服务器内按当前可见性刷新封面池并移除失效条目，不能把样板快照直接当成永久公开池。

## 本轮复查

`scripts/check_login_wall.cjs` 通过：

- 双主题 × 8 种视口共 16 组：无横向溢出、无缺图、axe 无报告违规。
- 随机排列、四行反向位移、上下移动不影响背景、面板位置固定、空闲停止动画。
- 手机静态和减少动态效果降级。
- 登录失败保留账号、注册切换、图片请求失败后仍可操作登录。
- 截图和动效：`evidence/login-wall/`。

仍为本地五页样板阶段，未发布线上。初稿验收中的“三张分镜首次入场”已被本记录替代；其他四类样板未改变。
