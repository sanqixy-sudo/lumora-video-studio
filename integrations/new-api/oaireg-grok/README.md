# oaireg grok 专用插件

版本 `1.0.0`，插件标识 `oaireg-grok`。适用于已验证的 New API `v1.0.0-rc.40` / 插件 API v1。
后台上传 **plugin.js** 即可；其余文件为说明及离线测试，不需要上传。无需修改 New API 镜像。

## 模型与价格展示

| 模型 | 可视化定价行 | 唯一数值用量 | 单位 |
| --- | --- | --- | --- |
| `grok-imagine-video` | 480p、720p | 视频时长 `seconds` | 秒 |
| `grok-imagine-video-1.5-preview` | 480p、720p、1080p | 视频时长 `seconds` | 秒 |
| `grok-imagine-video-6s` | 1 行，固定6秒/480p | 生成次数 `requests` | 次 |

插件用 `usageProfiles` 为三个模型分别声明字段，不会让6s模型出现秒数价格或让普通版出现1080p。
**插件不包含任何售价，不修改后台价格，也不执行汇率换算。** 未配置价格时，模型应保持未定价；表单默认的零值不代表已经配置了免费价格。

进入“模型定价”，选择对应模型及本插件的定价项，切换到“可视化编辑器”：

- 普通版和1.5版：分别填写各分辨率行的“视频时长”每秒单价。
- 6s版：填写“生成次数”每次单价。
- 没有额外收费时，加收费用填0；保存前使用费用试算核对。
- 使用可视化编辑器生成表达式，保留对 `u("seconds")` 或 `u("requests")` 的引用。单纯填写常数表达式可能显示为“特殊计费表达式”，无法展示每秒/每次单价。
- 分组倍率及请求规则仍按现有 New API 设置执行。插件不会调整这些配置。

## 安装与绑定

1. 管理员进入“任务插件”，上传本目录的 `plugin.js`，核对名称 **oaireg grok 专用插件**、版本1.0.0。
2. 新建独立“任务插件”通道，绑定 `oaireg-grok`，填写上游根地址与密钥。地址不带尾部 `/v1`；插件补齐 `/v1/videos`。
3. 添加需要开放的上述模型，设置本地分组；上游密钥应具备文档所述 xAI / auto 分组访问权限。
4. 配置需要开放模型的价格，确认每个模型的可视化定价行数和单位与上表一致，再开放使用。

不声明或接管共享 OpenAI 通道类型。原有 Omni / Flow 专用插件不变。
如果已有其他通道供应相同 Grok 模型，需核对路由，避免请求继续走旧通用解析器。
模型别名应明确映射到一个受支持模型；不要用一个别名混合按秒和按次的模型。

## 请求行为

提交 `POST /v1/videos`、查询 `GET /v1/videos/{id}`；支持 JSON，参考图使用公网URL或 Data URI。
本版不接收 multipart 文件上传，错误会明确提示。插件没有网络副作用；上游调用由 New API 执行。

- 普通版、1.5版：`seconds` 为1–15整数，接受整数或数字字符串；未传时明确发送 `"6"`。
- 分辨率只取 `resolution`，未传时明确发送 `480p`。1.0不接受1080p。
- `size` 是旧画幅选择字段，不能用于推断收费分辨率。它被转换到最接近的9:16、16:9或1:1；显式 `aspect_ratio` 与 `size` 冲突则报错。
- 普通版、1.5版默认16:9。6s版默认9:16，固定发送6秒/480p；客户端其他秒数或清晰度不会增加收费次数。
- 单图别名归一化为 `image`（6s版为 `image_url`），多图归一化为 `reference_images`。同时提交多个图片字段时报错，避免部分素材被悄悄丢弃。
- 1.0仅单图；1.5的480p/720p和6s版最多7张；1.5的1080p多图会明确拒绝。
- 保留其他扩展JSON字段，但客户端传入的 `requests` 等字段不能改变插件计算的用量。

提交时根据归一化后的真实请求生成计费用量：普通版为秒数和分辨率，6s版始终1次。
完成钩子返回空增量，沿用 New API 已保存的提交用量，避免轮询次数或上游非计费字段改写账单。
失败结算与预扣退款由现有 New API 主程序处理。

只有明确 `completed` 且返回有效视频URL时才标记成功。下载支持GET/HEAD，下载地址不附带通道密钥。
